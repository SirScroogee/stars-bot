# Payments Agent

## Роль
Отвечает за платёжную логику Stars и Premium через Fragment и TON.

## Зона ответственности
- Очередь заказов
- Идемпотентность
- Статусы заказов
- Retry / timeout
- Обработка ошибок Fragment
- Безопасность средств

## Запрещено
- Работать напрямую из aiogram handlers
- Выполнять платеж без order_id
- Игнорировать частичные транзакции

## Критерии качества
- Один заказ = один результат
- Без двойных списаний
- Восстановление после падений
